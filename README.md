# OLX Monitor — нові оголошення OLX у Telegram

Скрипт стежить за видачею OLX з вашими фільтрами (наприклад, оренда квартир у місті до певної ціни) і надсилає нові оголошення в Telegram, щойно вони з'являються.

> Це вітринна копія робочого проєкту: без реальних chat ID, токенів і робочої бази. Автозапуск за розкладом тут вимкнено.

## Як це працює

1. GitHub Actions запускає перевірку кожні ~5 хвилин (лише з 08:00 до 22:00 за Києвом).
2. Playwright відкриває сторінку OLX як справжній браузер, BeautifulSoup розбирає картки оголошень.
3. ID оголошень звіряються з базою `seen_ids.json`, яку workflow сам комітить назад у репозиторій.
4. Нові оголошення приходять у Telegram: назва, ціна, посилання. Отримувачів може бути кілька.

Приклад сповіщення:

```
🏠 2-кімнатна квартира біля центру
💰 12 000 грн.
🔗 https://www.olx.ua/d/uk/obyavlenie/...
```

## Що всередині

- **Без дублів:** кожне оголошення надсилається один раз; перший запуск лише зберігає поточну видачу як базу.
- **Без «ТОП»-оголошень:** промо-картки, які OLX піднімає нагору, пропускаються.
- **Робочі години:** вночі перевірка не запускається, з урахуванням літнього й зимового часу.
- **Стійкість:** lock-файл не дає запускам накладатися; якщо OLX змінив розмітку або показав капчу, сторінка зберігається для діагностики, а помилки пишуться в журнал.
- **Тестовий режим** `--test`: надсилає 2 сповіщення, не чіпаючи робочу базу.
- **Режим циклу** `--loop` для запуску на VPS з випадковим інтервалом 1–3 хв.

## Запуск

**GitHub Actions**

1. Settings → Secrets and variables → Actions → додайте секрети `TELEGRAM_TOKEN` і `TELEGRAM_CHAT_IDS` (через кому).
2. Там же у вкладці Variables додайте `OLX_SEARCH_URL`: посилання на видачу OLX з вашими фільтрами.
3. У `.github/workflows/olx-monitor.yml` розкоментуйте блок `schedule`.

**Локально**

```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env   # впишіть свої значення
python send_advertisement.py --test
```
